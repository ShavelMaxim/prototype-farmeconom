## Изменения начального рендера

- Первые 12 карточек находятся в настоящем SSR HTML; «Показать ещё» раскрывает следующие 12. Все 44 товара участвуют в поиске и фильтрации, все статические страницы сохранены. Параметр page в URL восстанавливает раскрытие при Back/reload; изменение условий сбрасывает page. После раскрытия фокус переходит на первый новый товар.
- На телефоне не гидратируется скрытая desktop-панель. useDesktopLayout совпадает с CSS-порогом 901 px; DesktopFilters загружается динамически только на широком экране. Мобильные поля создаются в Drawer. Desktop-placeholder сохраняет колонку; панель ограничена высотой viewport и прокручивается с клавиатуры.
- Сокращён реальный объём стартовой разметки и контролов. Гидратация не откладывается искусственным idle-таймером, контент не скрывается ради метрик. Ant Design / Redux / RHF / Zod сохранены; новых зависимостей нет. Для простых элементов используется семантический HTML, AntdBoundary остаётся у потребителей.
