# Насыщенный графит — 8 ноября 2026

Пользователь выбрал графитовый вариант с аквамариновым акцентом и разрешил перенос макетов в существующее приложение. Стек и размещение на GitHub Pages сохраняются. Название интерфейса — «Фарм Эконом».

## Что изменено

- Графитовые шапка и главный блок, аквамариновые действия с тёмным текстом, светлый каталог. Системный Segoe UI без загрузки шрифтов. Товарная графика использует существующий ProductArtwork, без новых изображений и сетевых ассетов.
- Настольная главная: поиск, главный блок, быстрые ссылки на разделы и рабочая панель фильтров. Мобильный первый экран: поиск, категории, сортировка и фильтры; большой hero скрыт. Сохранена измеряемая нижняя навигация.
- Карточки, круглые кнопки избранного 44×44, общие кнопки, формы, товар, корзина, история и избранное используют общую палитру. Декоративные иконки не попадают в доступные названия ссылок. Оба триггера фильтров возвращают фокус на себя.
- Новогодний слой включается звездой в шапке: лёгкая гирлянда, шапочка на знаке и акцент в hero. CSS без таймеров, canvas, постоянной анимации и запросов; pointer-events:none. По умолчанию отключён. В контрастных схемах скрыт, выбор остаётся сохранённым.
- Старые ключи корзины/personal:v1, товарные id/slug, URL-фильтры и снимки заказов сохранены. Optional display.festive совместим с прежними настройками, bootstrap применяет его до отображения. Модульная проверка защищает восстановление старых данных.
- Учебные подписи убраны из UI и метаданных. Помощь описывает пользовательские действия. Диагностика сети перенесена за ?diagnostics=1; проверки ошибки API сохранены. Внутренние имена адаптеров и техническая документация не переименованы ради маскировки.
- Оформление остаётся локальным: «Сохранить заказ», явное подтверждение сохранения на устройстве, статус истории «Сохранён на устройстве». Передачи в аптеку/бронирования/оплаты нет. Медицинские предостережения об инструкции и консультации сохранены; фильтры не подтверждают применимость или взаимозаменяемость.
