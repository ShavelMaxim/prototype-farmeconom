# Расширение интерфейса — 7 ноября 2026

Новый запрос пользователя расширяет прежний объём после завершённых 10 этапов. Стек, Pages и запрет настоящих покупок/персональных данных сохраняются. Исходная опубликованная версия: 2b79da1.

## Сценарии и экраны

- Мобильный каталог: компактная шапка, поиск, категории, сортировка, фильтры в Drawer с отдельным черновиком и кнопкой «Показать N товаров». Закрытие/Escape отменяет черновик, применение создаёт одну запись History. Выбранные условия видны над выдачей, доступны сброс и удаление одного условия.
- Desktop: фильтры в боковой панели. На планшете — тот же Drawer. Нижняя мобильная навигация: каталог, избранное, корзина, заказы; подписи, aria-current, safe-area. Открытые панели не перекрываются.
- Избранное: кнопка на карточке/товаре, отдельная страница, localStorage, удаление с отменой. Общая подписка сетки, без подписок на каждой карточке.
- Мои заказы: только завершённые демо-оформления пользователя, без выдуманной предварительной истории. Снимок названий/цен/количества/аптеки/дня, дата, раскрываемый состав, повтор с проверкой текущего наличия и подтверждением перед изменением корзины. Статус «Демо завершено», без выдуманной доставки.
- Настройки отображения: масштаб текста, контрастная/светлая/тёмная схемы, интервалы, reduced motion, сохранение, сброс. Основной интерфейс доступен без включения режима. Проверка клавиатуры, увеличенного текста, 320px, axe — не полная сертификация WCAG.

## Данные и ограничения

Сохраняются существующие 24 товара и их slug/id. Добавляются учебные образцы новых категорий: лекарства, БАДы/витамины, питание, спортпит, материнство, косметика, ортопедия и гомеопатия. Все медицинские названия/характеристики синтетические, явно помечены; не выдавать их за инструкции или реальную пригодность.

Общие фильтры: категория, наличие, диапазон цены, бренд, аудитория, особенности. Зависимые: форма, дозировка, количество, действующее вещество. Аудитория: дети (точный возраст в месяцах/годах), беременные, кормящие, женский/мужской уход, уход за пожилыми, реабилитация. Для лекарств аудитория не является разрешением к применению; неизвестные медицинские данные никогда не превращаются в «подходит». Возрастные рамки демо не медицинская рекомендация. Особенности только из явных данных; «без сахара» не означает «при диабете».

Значения внутри одного множественного фильтра объединяются ИЛИ, разные фильтры — И. Пустая выдача сохраняет условия; запреты не ослабляются автоматически. Похожие товары показываются только по явной группе и с объяснением; терапевтическая взаимозаменяемость не заявляется.

## Критерии

Состояние в URL и Back/Forward, устойчивое восстановление повреждённого/недоступного storage, отсутствие действий до восстановления, индикация сохранения только на устройстве. Skeleton при первой загрузке новых страниц, прежние товары при обновлении. Toast не заменяет постоянную ошибку. Размеры touch-элементов от 44px, один столбец при узком экране/крупном тексте. AntD только у потребителей, исходный бюджет JS 750000 байт сохраняется. Проверки: типы, lint, модели, build, E2E новых и прежних сценариев, доступность/геометрия/бюджет, Lighthouse. Публикация и локальная реализация фиксируются отдельно.
