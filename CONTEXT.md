# Контекст для продолжения

## Запрос пользователя

Самостоятельно создать проект по шагам и вести актуальный план, чтобы не требовалось повторять решения. Портфолио к собеседованию на frontend/web-разработчика в Фармэконом в понедельник 9 ноября. Важны современное поведение интерфейса, скелетоны, отсутствие скачков и блокирующих лоудеров.

## Решения

- Самостоятельный концепт «Аптека рядом», с явной отметкой учебного проекта; не выдаём себя за Фармэконом.
- Next.js App Router + TS; React совместимой актуальной версии вместо ограничения React 18. Ant Design + CSS Modules.
- Redux Toolkit и RTK Query сохраняем по пожеланию пользователя. Данные SSR не пропускаем через клиентский Redux.
- FSD без избыточной вложенности. Моковые Route Handlers. PHP/MySQL отложены.
- Каталог является главной страницей: акцент на поиске/получении, без рекламной перегрузки.
- Простая форма демо-получения без сбора персональных данных. Отдельная тестовая возможность задержки/ошибки API для проверки состояний.

## Состояние

Этапы 1–9 завершены: каталог, карточки, корзина, аптеки, оформление, API и проверки. Этап 10 частично выполнен (README, INTERVIEW.md, скриншоты); внешняя публикация ещё не выполнена. Исходники отформатированы Prettier; в папке приложения инициализирован локальный Git без удалённого репозитория.

Версии закреплены: Next 16.4.5, React 19.3.1, AntD 6.7.0, TS 6.0.3. Проверки прошли: TypeScript, ESLint, 16 unit/integration/API тестов, 12 E2E (desktop/mobile), production build. После мобильных CSS-исправлений также прошли все 6 мобильных E2E. Скриншоты находятся в docs/screenshots. Это концепт, не окончательный согласованный дизайн и не production-магазин.

Исправление, которое нельзя потерять: Providers создаёт пару store/serverState один раз через lazy useState. serverState — неизменный начальный снимок для React Redux Provider. localStorage восстанавливается отдельным CartPersistence внутри Provider. Без стабильного serverState при прямом входе в статическую карточку DOM мог сохранять disabled-атрибут после раннего восстановления корзины. Этот сценарий покрыт E2E. Не удалять serverState как кажущийся лишним.
